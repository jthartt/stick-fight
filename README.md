# Stick Fight!

A garage kid with a cardboard drum kit vs. a ladder of boss drummers. The boss plays a beat — you play it back.

**Keys:** D = hi-hat · F = kick · J = snare · K = tom · Space = start/next · M = mute

No build step: plain HTML5 Canvas + Web Audio (all drums synthesized). Run locally with `npx http-server .`
